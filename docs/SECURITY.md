# 安全说明

## 请勿提交或报告的内容

本仓库公开。Issue、日志和附件中请勿包含账号、密码、Cookie、访问令牌、
Home Assistant 备份、`.storage` 文件、设备编号、录像编号、签名 URL、云端原始响应、
真实家庭事件时间、录像或缩略图。

报告问题时只提供：集成版本、Home Assistant 版本、目标型号、固定错误码、是否为
只读预检，以及经过人工去标识的复现步骤。

## 运行时边界

- 集成不提供登录表单，也不读取 `hass-xiaomi-miot` 的认证存储。
- 云端私有标识不会进入 Home Assistant Store 或诊断下载。
- 历史 Store 只增加不对外显示的时间边界、完成布尔值和页数；诊断不返回真实事件时间。
- 网络请求拒绝明文 HTTP、字面私网地址、本地域名和不安全重定向。
- 媒体工具命令行不含任何远端地址或解密材料。
- 输出不会覆盖已有文件；存在未决 partial 文件时会停止。
- 自动保留策略不会删除未被本集成状态登记的文件。
- 最终发布依赖同目录硬链接，确保目标在竞态中出现时也不会被覆盖；不支持该能力的
  文件系统会安全失败。

## 已知风险

这是非官方私有接口。上游可以改变响应结构、加密形式、CDN 主机或授权规则。
域名的 DNS 解析仍由运行环境和系统解析器信任；建议把 Home Assistant 放在受控网络中，
并限制其不必要的出站能力。首次真实运行前应先调用 `dry_run: true`，再使用单独的测试
目录验证一条无敏感内容的样本。
