# 待办与未决项

1. 在用户提供可用 HA 登录会话后，只调用一次 `run_backup` 且设置 `dry_run: true`；
   记录时只保留固定结果码和计数，不读取或输出认证值、设备编号或媒体地址。
2. 在单独授权真实下载后，再选择无敏感内容的事件下载一条样本；不得提交录像或私有
   标识。
3. 在已有的 Home Assistant 网络媒体挂载上验证重启、断网重试、空间不足与连续每日
   计划；没有目标环境证据前保持 `UNKNOWN`。
4. 评估其他门锁型号；不得因型号字符串相似就宣称兼容。
5. 按真实样本证据决定是否支持 master playlist、`EXT-X-MAP` 或其他加密格式。
6. 陌生人识别若进入后续版本，应采用独立、默认关闭的本地处理边界，并另行解决告知、
   保留期限、误报和生物特征隐私问题。
