# 发布证据

## V0.0.3 - 2026-08-28

### 范围

新增独立、显式和可恢复的历史回填服务。云端空事件页只有在继续标记结束时才视为
历史终点；继续游标必须严格向过去移动。单页未全部成功或隔离时不提交下一页游标，
旧录像成功不会倒退每日增量游标。服务响应和诊断只增加固定状态、计数与布尔值。
