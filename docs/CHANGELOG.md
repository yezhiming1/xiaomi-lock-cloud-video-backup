# 变更记录

## V0.0.3 - 2026-08-28

- 新增 `run_history_backfill`，使用与每日增量独立的持久历史游标。
- 识别 `isContinue` 与 `nextTime`；空事件页仍可继续向更早时间扫描，游标停滞时固定失败。
- 只有一页全部成功、已存在或完成三次失败隔离后才提交下一页，避免上限或失败导致漏项。
- 每次最多扫描 20 页、串行选择 100 条；只读预检不初始化或更新历史状态。
- 历史服务不执行保留删除，避免补录动作顺带移除既有媒体。
- 历史旧事件只以 `max` 方式影响每日游标，保证不会倒退增量位置。
- 诊断新增历史完成布尔值和已提交页数，不返回历史时间、录像编号或云端原始响应。

## V0.0.2 - 2026-08-28

- 同一物理设备出现在多个已加载云会话时按内存设备编号去重。
- 云设备列表没有目标型号时，允许从 Xiaomi Miot 已加载实体索引恢复目标绑定；实体云对象
  仍必须属于已加载会话。
- 把零目标和多个不同目标分别折叠为 `TARGET_MATCH_NONE` 与
  `TARGET_MATCH_MULTIPLE`，不在错误中包含设备编号。
- 统一诊断与下载请求的集成版本为 `0.0.2`。

## V0.0.1 - 2026-08-28

- 新增无凭据配置的 Home Assistant 自定义集成。
- 复用 `hass-xiaomi-miot` 已加载的内存云会话。
- 新增有界事件分页、增量游标、摘要去重和三次失败隔离。
- 新增 AES-128 HLS 分片内存解密、本地重封装、合并与 MP4 验证。
- 新增 `/media` 路径约束、原子发布和仅项目登记文件的保留清理。
- 新增每日计划、手动只读预检服务和去标识诊断。
- 新增合成端到端测试、公开树隐私审计与固定 Home Assistant 镜像导入测试。
